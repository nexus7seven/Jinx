# Decision Engine Rule Sources

The decision engine must distinguish authoritative supplied rules from learned precedent and inference.

Current workbook-derived criteria are stored in the existing partner/IP knowledge directories. Each imported line retains its workbook filename, sheet and row number in the text.

Important interpretation rule: a creditor representative or voting-house rule is not automatically a case rejection. Calculate that representative's voting exposure and assess whether the rule is decisive in the full voting landscape.

Do not silently merge conflicting rules between IPs or workbooks. Treat them as scoped rules and surface the conflict.

Learned case outcomes must not overwrite authoritative rules. Store them as precedent/correction records and use them as supporting operational evidence only.
