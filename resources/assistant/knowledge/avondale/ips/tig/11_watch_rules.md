# TIG — WATCH Rules

Source workbook: Avondale - TIG criteria(1).xlsx, sheet Watch Criteria.

- [Row 5] Will want evidence of any vulnerabilities being used to be outside of the below criteria.
- [Row 7] Will reject IVA if debt can be paid off in less than 6 years
- [Row 9] Will reject IVA if Bankruptcy dividend is higher than IVA
- [Row 11] Will reject IVA if equity is greater than debt
- [Row 13] Will reject if the client only has debt with 1 lender (Need sperate lender account of more than £500)
- [Row 15] Will reject (on all accounts) if any spending within 3 months
- [Row 17] Will reject if the client has children over 13 and no sustainability Paragraph (Drafter)
- [Row 19] Will abstain (not vote) if client aged 80 or above
- [Row 21] Will request for car to be downgraded to £4,500 if more than £9,000 and funds brought into IVA
- [Row 23] Will modify if car HP is >£400 per month (unless family help or we can evidence a valid reason)
- [Row 25] Will require 3 months clean bank statement if gambling is the main cause of debt problem
- [Row 27] If the IVA has been proposed previosuly - the main content (I&E, assets, liabilities) needs to remain the same or a reason for the changes
- [Row 29] Will reject all cases where antecedent transactions appear, irrelevant of the dividend factor
- [Row 31] Will reject if car finance in last 3 months, without evidence of valid reason (eg old car scrapped with proof)
