# Avondale Partner Baseline

## Purpose

This document contains partner-level rules that apply to Avondale cases unless superseded by a more specific IP-level rule.

## Partner Structure

Avondale may place cases with the following IP destinations:

- Lawson Fox
- TIG
- Assure
- Anchorage Chambers

Each IP may have its own eligibility, evidence and packaging criteria. Those criteria must be treated as separate IP-level knowledge and must not be blended together.

## I&E SFS Rule

For Avondale cases, the applicable SFS-controlled sections must be built to **65% of the relevant SFS maximum guideline**.

This applies across Avondale's IP destinations unless a later confirmed IP-specific rule explicitly changes the treatment.

SFS-controlled sections currently include:

- Housekeeping / Groceries
- Communication & Leisure
- Personal

When calculating an Avondale I&E, use the household-composition SFS maximum for each applicable section and set the target section amount to:

`SFS target = SFS maximum x 65%`

Retain source precision internally and round the final displayed section amount upward to the nearest £1 where the wider I&E rules require that presentation treatment.

The 65% rule is a partner-level rule. It does not replace separate IP eligibility or packaging criteria.

## Knowledge Precedence

When rules conflict, use the most specific confirmed rule:

1. IP-specific rule
2. Avondale partner-level rule
3. Company-level rule

Case-specific facts do not become organisational rules.
