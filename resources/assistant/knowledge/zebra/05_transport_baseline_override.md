# Zebra I&E — Public Transport Baseline Override

This rule supersedes the earlier Zebra public-transport base-calculation wording in `03_expenditure_I&E_calculation_rules.md`.

Where the client or partner has established that they use public transport rather than a car:

- do not ask for a monthly public-transport amount in the normal I&E interview;
- include **£60 per month per applicable adult** as the deterministic base public-transport expenditure;
- public transport remains flexible up to **£120 per month per applicable adult**;
- use SFS headroom before increasing public transport above the £60 base for target-DI optimisation;
- never leave public transport at £0 merely because the target DI can be reached using other expenditure categories;
- never duplicate the allowance across household members;
- if an explicit valid public-transport amount has already been established outside the normal flow, use that amount instead of the £60 base, subject to applicable Zebra rules.

This is a calculated transport rule, not an additional chatbot question.
