# IVA Dividend and Target DI Calculation

Use this calculation when an agent asks what target DI / monthly IVA contribution is required to achieve a specified dividend.

Inputs:
- Total qualifying debt
- Required dividend in pence in the pound, converted to a decimal (for example 60p = 0.60)
- IP fees: £3,935
- Standard IVA term: 60 months

Calculation:
1. Add £3,935 IP fees to the total debt.
2. Multiply that total by the required dividend decimal. This gives the total amount required over the IVA for the dividend calculation.
3. Divide the result by 60 months to calculate the target monthly DI/contribution.

Formula:
Target DI = ((Total Debt + £3,935) x Dividend Decimal) / 60

Example for £10,000 debt and a required 60p dividend:
(£10,000 + £3,935) x 0.60 = £8,361
£8,361 / 60 = £139.35 target DI per month

If the required target DI cannot be achieved over 60 months, a 72-month IVA can sometimes be considered where appropriate. Recalculate by dividing the required total by 72 instead of 60.

72-month example using the same figures:
£8,361 / 72 = £116.13 target DI per month

Do not assume a 72-month term is automatically available; describe it as an option that can sometimes be considered.
